## Просмотр

Откройте `index.html` локально: это галерея с навигацией между макетами, без сервера и внешних зависимостей. Кнопки внутри статических экранов описывают предполагаемое поведение; работа с API не реализована.

В репозитории полный набор исходников и PNG хранится в `design-package.zip` с сохранёнными папками. Для быстрого просмотра отдельно приложены три PDF, `dashboard.png`, автономная галерея `index.html` и документы передачи. Ниже перечислены пути внутри распакованного архива.

- `svg/01-dashboard.svg` — детальный дашборд SCR-01.
- `wireframes.pdf` — SCR-02, расчёт счёта, SCR-03 с панелью события, SCR-04 со созданием и подключением, SCR-10.
- `ui-kit.pdf` — цвета, типографика, базовые элементы и состояния.
- `user-flows.pdf` — F1–F3.
- `svg/` — редактируемые исходники всех 17 листов, пригодные для импорта в Figma.
- `png/` — превью всех листов. Листы 12–15 показывают четыре состояния для каждого из основных экранов.
- `handoff.md` — поведение, ограничения и вопросы для реализации.
- `coverage.md` — соответствие требованиям и оставшиеся проверки.
- `repository-alignment.md` — сопоставление с уже сделанной работой команды и вопросы по модели данных.

## Объём второго показа

Детальный дизайн дашборда; wireframes счёта, событий и подключения; служебные состояния; схемы F1–F3; базовый UI-kit и список компонентов. Реализация рабочего дашборда, API, 6–8 правил тарификации и тестов остаётся задачей разработки.

Тарифы, клиенты, аудит, калькулятор, детальный UI счёта и событий, полноценная планшетная адаптация относятся к последующим показам.

## Данные и точность

Пример Acme Corp / Standard v2 / ноябрь 2026 зафиксирован на 05.11.2026, как в разделе 9 ТЗ. Это демонстрационные, а не текущие данные.

Начисления 1 228,00 ₽ − бесплатный лимит 660,00 ₽ = 568,00 ₽. Cold start 61,60 ₽ уже включён в вычисления 992,00 ₽. Стоимость топа функций по прайсу — 1 240,00 ₽; она отличается от начислений с учётом ступеней и от нетто после лимита.

Среднее время 245 мс и доля ошибок 0,8 % в карточках — демонстрационные показатели: в ТЗ их агрегатные значения отсутствуют. В топе по функциям отсутствующие метрики обозначены «—». Столбцы графика, время последних событий, event_id, время получения и хэш — примеры оформления, не согласованные расчётные данные. Исторический график не следует восстанавливать из итоговых сумм.

## Как зафиксировать

Рекомендуемое расположение комплекта: `docs/design/`. Отдельная ветка: `design/showcase-2`. Коммит: `docs(design): add showcase 2 design package`. Запрос на слияние в `main`, без изменения кода приложения. Авторство коммита должно соответствовать реальному аккаунту; чужие имя и почту не подставлять.

В облачное пространство команды можно загрузить те же PDF и ссылку на Figma. Доступ проверяющих к приватному репозиторию и допустимость GitHub вместо Сфера.Код согласовывает Team Lead.
