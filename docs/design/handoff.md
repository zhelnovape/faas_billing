# Передача дизайна разработчику

## Дашборд

Пять KPI: стоимость, вызовы, среднее время, доля cold start и доля ошибок. У каждого определение метрики по наведению и фокусу. Для текущего месяца показывать net с пометкой «оценка», для остальных периодов — cost_list с подписью «по прайсу, без лимитов и скидок». Деньги не окрашивать в красный или зелёный.

Периоды: 1 час, 24 часа, 7 дней, 30 дней, текущий месяц, произвольный интервал. Фильтры клиента и функции зависимы. В операторском режиме доступно «Все клиенты»; при выборе одного клиента показывать его тариф. В клиентском режиме скрыть выбор других клиентов и административные действия. Режим, период, клиент и функция сохраняются в URL. Сброс возвращает текущий месяц и все функции выбранного клиента.

Автообновление — каждые 5 секунд. Пауза меняет подпись на «Продолжить». При неактивной вкладке опрос приостанавливается. При ошибке обновления старые значения остаются; баннер «Данные устарели, повтор через N с». Более 60 секунд без событий — нейтральное «Нет новых событий», не авария.

График переключается между вызовами и стоимостью. Шаг: минута / час / день в зависимости от периода, с ручным переключением. В подсказке точное время, значение и активные фильтры. Нули вместо разрывов. Числовые значения осей брать из API; в макете столбцы иллюстративные.

Таблица функций сортируется по столбцам; по умолчанию стоимость по убыванию. Первые 10 строк и «Показать все» при большем количестве. Нажатие функции применяет фильтр и позволяет открыть события этой функции. Сумма топа по прайсу не равна итогу счёта после бесплатного лимита.

## Счёт

US-08–12: календарный месяц, текущий помечен предварительным; строки каждой ступени, вычисления, общий блок credits, итог. Если тариф менялся, показывать секции по версиям и датам; бесплатный лимит отдельно с указанием версии на начало месяца. Бейдж открывает параметры только для чтения. Цена версии неизменяема.

«Как это считается» открывает панель формулы, значений и результата. Cold start в Standard v2 уже включён в вычисления. Раскрытие функции показывает вызовы и вычисления до лимитов; лимит применяется к счёту целиком. Данные денег приходят строками; интерфейс не пересчитывает суммы. Кнопки экспорта и диаграмма структуры — Should, не условие завершения текущего дизайна.

## События

Таблица с UTC до миллисекунд, функцией, длительностью, init, памятью, статусом, cold start и справочной стоимостью. Фильтры: период, функция, статус, cold start; поиск event_id. Курсорная подгрузка, не выдумывать общее количество. В панели — исходные поля, округление, billed duration, ГБ·с, версия тарифа, составляющие, event_id, время получения, хэш и копирование. Повторы не увеличивают счёт. Вкладка отклонённых показывает причину.

## Функции и подключение

Список, создание (имя, память по умолчанию, описание) и три шага подключения. Ошибка имени рядом с полем. Успех ведёт к подключению. Доступные статусы: активна, нет событий более суток, отключена. Оператору — создание и демо; клиенту — чтение списка и инструкции. Административный ключ запрашивается однократно, без регистрации и отдельного экрана входа.

Ключ маскирован, показать/скопировать по действию пользователя. Не использовать настоящие секреты в макетах, PDF, экспортах и репозитории. Пример запроса в макете схематичен. Полные curl/Python и обязательные поля сверить с OpenAPI и Документом 2: он не предоставлен в этой работе. Ответ теста: принято / дубль / отклонено с причиной. Успех → дашборд.

## Состояния и доступность

Матрица SCR-01–04 × данные / загрузка / пусто / ошибка / нет связи. В каждой загрузке скелетон именно соответствующей таблицы или карточек. Пусто — описание и доступное роли действие. Ошибка первоначальной загрузки — текст, request_id и «Повторить». При потере связи после успешной загрузки сохранять данные.

Все действия доступны Tab и Enter/Space, видимый фокус 2 px в цвете #2455C7. Escape закрывает панели и возвращает фокус инициатору. Смысл ошибок и предупреждений передаётся текстом и значком. Основной текст #17243B, вторичный #536278 на белом или #F4F7FB; проверить контраст 4,5:1 при реализации и hover/disabled.

Arial с кириллицей, табличные цифры при реализации, суммы вправо, идентификаторы копируемые. Размеры: заголовок 28, раздел 20, основной текст 16, таблица 13–14, подписи 12–14 px. Основа сетки 8 px. На 1280 px таблицы допускают горизонтальную прокрутку внутри контейнера, без наложения текста; полноценная планшетная адаптация — следующий этап.

## Следующие итерации

Сверить с фронтендером фактический OpenAPI; заполнить отсутствующие агрегаты из API; проверить основной сценарий на 1280 px; оформить настоящие компоненты и варианты Figma, Auto Layout и прототипные связи; получить принятие Team Lead. Визуальный UI-kit не является готовой кодовой библиотекой.
